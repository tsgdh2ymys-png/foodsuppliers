# 🥕 FoodSuppliers — сервис поиска и сравнения поставщиков продуктов питания

Прототип сервиса, который помогает закупщику food-бизнеса **быстро находить поставщиков**
(ингредиенты, готовая продукция, упаковка и др.), **собирать по ним ключевую информацию**
и **сравнивать, с кем выгоднее связаться**.

> Часть 2 тестового задания. Цель — показать продуктовую логику и рабочий прототип, а не прод-систему.

---

## 🎯 Какую проблему решает

Закупщик (кафе, пекарня, производство, частная марка) ищет поставщиков по десяткам сайтов,
Telegram-чатов и выставок. Информация разрозненная и в разных форматах — тяжело **сравнить** и
понять, **кому написать первым**. Существующие B2B-каталоги — «жёлтые страницы»: много шума,
нет удобного сравнения.

**Наш угол:** не очередной каталог, а **инструмент принятия решения** — единые карточки +
сравнение ключевых параметров бок о бок под задачу конкретного закупщика.

---

## ✨ Возможности

По ТЗ:
- 🔎 **Поиск по категории товара** + текстовый поиск (по названию, описанию, городу и региону)
- 📍 **Фильтр по городу**; регион работы ищется текстом
- 🗂 **Единые карточки** с ключевой информацией
- ☎️ **Контакты, сайт и источник** (у реальных поставщиков — ссылка на первоисточник)
- ⚖️ **Помощь в решении** — сравнение поставщиков бок о бок (см. ниже)

Дополнительная информация по каждому поставщику (по ТЗ): минимальный объём заказа,
примерная цена, документы/сертификаты, условия доставки, регион работы,
**редакционный комментарий** и **личные заметки**.

Расширения:
- 🏷 **Фильтр по типу данных** — реальные (со ссылкой-источником) / тестовые (синтетика)
- ⭐ **Избранное** и 📝 **личные заметки** по поставщику
- ➕ **Добавление своего поставщика** (мини-CRM)

### Как помогаем принять решение
Пользователь отмечает 2–4 поставщиков чекбоксом в каталоге и открывает страницу **сравнения**:
ключевые параметры (город, регион, мин. заказ, цена, сертификаты, доставка, комментарий, контакты)
выводятся **бок о бок в одной таблице** — видно отличия и легко решить, с кем связаться.

> **Осознанное продуктовое решение.** На раннем этапе была версия со взвешенным «скорингом»
> (баллы 0–100, слайдеры важности). От неё отказались: при сравнении 2–3 поставщиков
> относительные баллы вводили в заблуждение (худшее значение в наборе показывалось как «0»,
> будто данных нет), а сам балл выглядел как «ложная точность». Прозрачная таблица —
> честнее и понятнее. Взвешенный скоринг остаётся кандидатом в backlog, когда данных будет больше.

## 🧱 Архитектура и выбор формата

| Слой | Технология | Почему |
|---|---|---|
| Backend | **FastAPI** | быстрый старт, типизация, понятные роуты |
| Шаблоны | **Jinja2** | server-side рендеринг, ничего лишнего |
| UI | **Tailwind (CDN)** | аккуратный вид без шага сборки |
| БД | **SQLite через SQLAlchemy** | ноль конфигурации для прототипа; переезд на PostgreSQL — одной переменной `DATABASE_URL`, код не меняется |

**Почему именно так:** для тестового задания важнее всего быстрый рабочий прототип с честным,
понятным UX. Тяжёлый фронтенд-фреймворк и Postgres здесь были бы оверинжинирингом; архитектура
при этом расширяема (слой данных и шаблоны разделены, БД абстрагирована).

```
app/
├── main.py        # роуты FastAPI (поиск, карточка, избранное, заметки, сравнение, добавление)
├── database.py    # подключение к БД (SQLite → легко на Postgres через DATABASE_URL)
├── models.py      # модель Supplier
├── seed_data.py   # реальные (найденные) + тестовые данные и комментарии
├── templates/     # base, index, supplier, compare, add
└── static/app.js  # панель выбора поставщиков для сравнения
```

## 📊 Данные

База наполняется автоматически при первом запуске (`app/seed_data.py`, идемпотентно):
**42 поставщика в 12 категориях** — **28 реальных + 14 тестовых**.

- **Реальные** (бейдж «● реальный», у каждого — ссылка на сайт-источник, найдены веб-поиском):
  - *Ингредиенты:* ГК «Союзоптторг», НЕОС ИНГРЕДИЕНТС, АСИЛАБ, ТД «Аргол»
  - *Упаковка:* RUSFLEX, Эдельвейс
  - *Бакалея и специи:* Арикон Групп, Айдиго, Verde Tech, ТД «Гурман»
  - *Молочная продукция:* Мос-Милк
  - *Замороженные продукты:* Русагропром
  - *Готовая продукция:* Лина, GFC
  - *Напитки:* OnlyHoreca, ОнТап
  - *Мясо и птица:* Меридиан
  - *Овощи и фрукты:* EvroFresh
  - *Рыба и морепродукты:* ПТК Экор-Фиш, Рыбный Порт, SeafoodLine
  - *Хлебобулочные и выпечка:* GF Premium Bakery, ТД «ЛФБ», Балтийский хлеб
  - *Дистрибьюторы HoReCa (мультикатегория):* Свит Лайф Фудсервис, EastFood, MARR RUSSIA, ОПТ-Торг HoReCa

  Города: Москва, Санкт-Петербург, Екатеринбург, Краснодар, Новосибирск, Казань, Ростов-на-Дону.
  У реальных B2B-поставщиков цена, мин. заказ и часть документов закрыты («по запросу») —
  в таких полях честно стоит «нет данных», мы их **не выдумываем**.

- **Тестовые** (бейдж «⚙ тестовый») — синтетические карточки с полностью заполненными полями
  (включая числа), чтобы наглядно показать сравнение во всех категориях.

## 🚀 Запуск

```bash
# вариант 1 — скриптом
./run.sh

# вариант 2 — вручную
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Открыть: **http://127.0.0.1:8000**

> ⚠️ macOS: если проект лежит в `~/Documents` и терминал получает `Operation not permitted` —
> это защита приватности (TCC). Выдайте терминалу **Full Disk Access** (System Settings →
> Privacy & Security) или перенесите проект в обычную папку (например, `~/`).
